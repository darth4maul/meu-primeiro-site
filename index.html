# 🥋 Quizizz de Lutas - Martial Arts Quiz Game

Um aplicativo web interativo estilo Quizizz com tema de Artes Marciais e Lutas, desenvolvido com HTML5, Tailwind CSS e JavaScript Puro.

## 🚀 Funcionalidades

- 🥊 **Perguntas Variadas**: Judô, Jiu-Jitsu Brasileiro (BJJ), Muay Thai, Karate, Boxe, Taekwondo, Capoeira e MMA.
- ⏱️ **Timer Dinâmico**: Tempo regressivo para cada pergunta com bônus por velocidade.
- 🔥 **Sistema de Combo/Streak**: Bônus de pontuação ao acertar respostas em sequência.
- 🔊 **Efeitos Sonoros**: Audio sintetizado direto via Web Audio API (sem dependência de arquivos externos).
- 🏆 **Ranking com LocalStorage**: Salvamento local do placar e historico dos melhores lutadores.
- 📱 **100% Responsivo**: Layout otimizado para celulares, tablets e computadores.
